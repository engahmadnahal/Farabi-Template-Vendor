# Farabi Academy - منصة فارابي التعليمية

منصة تعليمية احترافية مع دعم كامل للغتين العربية والإنجليزية.

## المميزات

- ✅ تصميم Premium مستوحى من أفضل المنصات التعليمية
- ✅ دعم كامل للغتين (العربية RTL والإنجليزية LTR)
- ✅ Responsive بالكامل للجوال والأجهزة اللوحية
- ✅ استخدام Tailwind CSS للتنسيق
- ✅ الهوية البصرية: الفستقي (#93C572) والكحلي (#000080)

## التثبيت

1. تثبيت المتطلبات:
```bash
npm install
```

2. بناء ملف CSS:
```bash
npm run build
```

أو للمراقبة التلقائية أثناء التطوير:
```bash
npm run build-css
```

## البنية

```
farabi cuorse/
├── index.html          # الصفحة الرئيسية
├── package.json        # إعدادات المشروع
├── tailwind.config.js  # إعدادات Tailwind مع الألوان المخصصة
├── src/
│   ├── input.css      # ملف CSS الرئيسي
│   └── main.js        # JavaScript للغة والتفاعلات
└── dist/
    └── output.css     # ملف CSS المُنشأ (يُنشأ بعد البناء)
```

## المكونات

### Navbar
- شعار Farabi Academy
- قائمة التنقل الرئيسية
- زر تبديل اللغة
- أزرار تسجيل الدخول والتسجيل

### Sidebar
- قائمة التنقل الجانبية
- الفئات التعليمية
- متجاوب مع الجوال (قابل للطي)

### Footer
- معلومات عن المنصة
- روابط سريعة
- روابط الدعم
- روابط وسائل التواصل الاجتماعي

## الألوان

- **Primary (الفستقي)**: #93C572
- **Secondary (الكحلي)**: #000080

## اللغات

المنصة تدعم التبديل بين:
- العربية (RTL) - الافتراضي
- الإنجليزية (LTR)

يتم حفظ اختيار اللغة في localStorage.
